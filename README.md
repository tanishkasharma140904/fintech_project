# 💰 Artho - Intelligent Financial Management Platform

Artho is a modern full-stack fintech platform designed to help users understand, manage, and improve their financial health through intelligent analytics, investment planning, debt management, and real-time collaborative expense sharing.

Unlike traditional expense trackers that only monitor spending, Artho provides a complete financial ecosystem where users can track expenses, analyze financial behavior, estimate investments, manage debt, and collaborate with friends or family on shared expenses.

# 👥 SplitUp by Artho (Flagship Feature)

A real-time collaborative expense-sharing system integrated directly into Artho.

Inspired by Splitwise but enhanced with Artho's financial intelligence ecosystem.

---

## What Makes SplitUp Special?

Unlike typical student projects that only demonstrate CRUD operations, SplitUp is a fully functional real-time multi-user system.

### Real Users Can:

✅ Create accounts

✅ Create expense groups

✅ Invite other registered users

✅ Add shared expenses

✅ Split bills equally

✅ Split bills by percentage

✅ Split bills by exact amounts

✅ Track balances

✅ Settle payments

✅ View activity history

✅ Receive real-time updates

---

## Real-Time Collaboration

Built using Firebase Firestore listeners.

When one member:

- Adds an expense
- Updates a settlement
- Creates a group

Every group member instantly sees updates without refreshing the page.

---

## Balance Simplification

SplitUp includes a balance simplification algorithm that minimizes the number of required transactions.

Example:

Instead of:

Rahul → Priya → Aman

The system simplifies to:

Rahul → Aman

Reducing unnecessary settlements.
